# ClonKR iPhone PWA — iOS-optimized GitHub Pages build

Upload the contents of this folder directly to the root of the `ClonKrIPhone` repository.

URL: https://jrkhaaled1.github.io/ClonKrIPhone/

This build removes runtime Babel, lazy-loads the large SehaOne network dataset, and avoids pre-caching the multi-megabyte application bundle. Google Calendar uses browser Web OAuth; WhatsApp Case Management is intentionally excluded from this PWA.
